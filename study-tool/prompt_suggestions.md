# اقتراحات تحسين الـ Prompts

## Prompt 1 — الترجمة مع التنسيق

### النسخة الحالية ✅

النسخة الحالية جيدة وواضحة. عندي اقتراحات بسيطة لتحسين جودة النتائج:

### التحسينات المقترحة

#### 1. إضافة تعليمات للجداول

السلايدات كثير فيها جداول، والـ AI ممكن يتجاهلها أو يفسدها.

```
الجداول (Tables):
- إذا وُجد جدول، أعد كتابته بنفس التنسيق كجدول.
- ترجم محتوى كل خلية مع الحفاظ على هيكل الجدول.
```

#### 2. تعليمات أوضح للاختصارات

الشرائح الأكاديمية مليانة اختصارات (CIA, AAA, NIST, etc.)

```
الاختصارات (Abbreviations):
- عند أول ظهور لأي اختصار، اكتب الاسم الكامل بالإنجليزية ثم الترجمة العربية.
- مثال: CIA - Confidentiality, Integrity, Availability (السرية، السلامة، التوافر)
```

#### 3. تحسين تعليمات الرسوم التوضيحية

التعليمات الحالية جيدة، لكن ممكن نضيف:

```
- إذا كان الرسم يحتوي على أسهم أو تدفق (flow)، اشرح الاتجاه والعلاقة بين العناصر.
- إذا كان الرسم مقارنة بين شيئين، اعرضها كجدول مقارنة.
```

#### 4. التعامل مع الأكواد

لو فيه أكواد أو أوامر في السلايدات:

```
الأكواد والأوامر (Code / Commands):
- اكتب الكود كما هو بدون تعديل.
- أضف شرح عربي مختصر بعد كل سطر أو كتلة كود.
```

---

### النسخة المقترحة الكاملة (Prompt 1)

```
نفّذ التعليمات التالية على المحتوى أعلاه (سلايد سلايد مرقمين):
قم بترجمة المحتوى الأصلي مع الحفاظ على التنسيق الدقيق التالي:

العناوين والمصطلحات: اكتب المصطلح باللغة الإنجليزية، متبوعًا بترجمته العربية بين قوسين.
مثال: User authentication: (مصادقة المستخدم)

النقاط والشرح: اكتب كل نقطة باللغة الإنجليزية، ثم أضف ترجمتها العربية الحرفية في نهاية الجملة.
مثال: The process of verifying an identity claimed by or for a system entity. (عملية التحقق من هوية يدّعيها كيان في النظام أو من أجله).

الاختصارات (Abbreviations):
- عند أول ظهور لأي اختصار، اكتب الاسم الكامل بالإنجليزية ثم الترجمة العربية.
- مثال: CIA - Confidentiality, Integrity, Availability (السرية، السلامة، التوافر)

الجداول (Tables):
- إذا وُجد جدول، أعد كتابته بنفس التنسيق.
- ترجم محتوى كل خلية مع الحفاظ على هيكل الجدول.

الأكواد والأوامر (Code / Commands):
- اكتب الكود كما هو بدون تعديل.
- أضف شرح عربي مختصر بعد كل سطر أو كتلة كود.

الرسوم التوضيحية والأشكال (Diagrams / Figures):
- إذا كان السلايد يحتوي على رسم توضيحي أو شكل أو مخطط (diagram, figure, flowchart, chart) أو أي إشارة لصورة مهمة:
  اشرح الفكرة التي يوصّلها الرسم كتابياً بشكل واضح ومفصل.
  اكتب: [رسم توضيحي]: ثم وصف الرسم وشرح فكرته.
- إذا كان الرسم يحتوي على أسهم أو تدفق (flow)، اشرح الاتجاه والعلاقة بين العناصر.
- إذا كان الرسم مقارنة بين شيئين، اعرضها كجدول مقارنة.
- لا تتجاهل أي رسم توضيحي مهم — حاول نقل المعلومة التي يوصّلها الرسم بالكلمات.

الهدف: إنشاء مرجع للمراجعة السريعة مع ترجمة دقيقة ومباشرة.

مهم جداً:
- حافظ على ترقيم السلايدات كما هو
- لا تحذف أي محتوى
- الترجمة العربية تكون بين قوسين بعد كل نقطة أو مصطلح إنجليزي
```
